# goptgs.com — PTGS site

Plain static HTML/CSS/JS. GitHub `main` is the single source of truth; Netlify
publishes every push to `main` automatically (about 1 minute).

## Editing copy (visual editor)
Copy lives directly in `index.html` and `about.html`. Edit it in CloudCannon's
Visual Editor: open the site at https://app.cloudcannon.com, pick a page, click
inside any yellow box, type, then **Save**. CloudCannon commits to GitHub `main`
and Netlify republishes.

The old `?edit=1` browser editor has been removed.
